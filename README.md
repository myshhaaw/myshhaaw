## 🧬 NEUROSCAN

### Parkinson's Disease Detection System

A multimodal AI system combining **MRI scans, tremor/video analysis,
and scribble tests** for automated Parkinson's disease assessment.

**What I built:**

- Integrated **3 diagnostic modalities**
- Developed **4 deep learning models**
- Implemented CNN and CNN-LSTM architectures
- Built multimodal feature fusion
- Achieved **94% accuracy, 93% precision, and 0.93 F1-score**
- Built an end-to-end Streamlit application
- Added real-time inference and visualization
- Implemented **Grad-CAM explainability**
